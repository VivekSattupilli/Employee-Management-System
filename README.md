# Employee Management System

## Description
This is a Java-based Employee Management System developed as a college project.

The project demonstrates Object-Oriented Programming (OOP) concepts such as abstraction, inheritance, and serialization. It is designed to manage employee information, and employee records can be stored in CSV format.

## Features
- Add employee details
- Display employee information
- Different employee types (Manager, Engineer, Sales Person)
- Object-Oriented Programming concepts
- CSV-based data storage

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- File Handling
- CSV

## Learning Outcomes
Through this project, I learned:
- Abstraction
- Inheritance
- Classes and Objects
- Serialization
- Basic file handling in Java
